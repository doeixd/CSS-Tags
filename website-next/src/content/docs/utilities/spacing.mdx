Spacing utilities use the compatibility `--spacing-*` scale, which is mapped
to the canonical density-aware spacing system.

## Padding and margin

Padding utilities are `.p-xs`, `.p-sm`, `.p-md`, `.p-lg`, and `.p-xl`. Margin
utilities use the same suffixes: `.m-xs` through `.m-xl`.

## Axis gaps

Use `.gap-x-xs` through `.gap-x-xl` for column gaps and `.gap-y-xs` through
`.gap-y-xl` for row gaps. They work with grid, flexbox, and the CSS Tags layout
primitives.

<LiveExample title="Tune row and column rhythm independently" description="This grid uses a large column gap and a small row gap without hardcoded lengths.">
  <div class="d-grid grid-cols-3 gap-x-xl gap-y-sm">
    <div class="bg-secondary-muted rounded-sm p-sm">One</div><div class="bg-secondary-muted rounded-sm p-sm">Two</div><div class="bg-secondary-muted rounded-sm p-sm">Three</div>
    <div class="bg-secondary-muted rounded-sm p-sm">Four</div><div class="bg-secondary-muted rounded-sm p-sm">Five</div><div class="bg-secondary-muted rounded-sm p-sm">Six</div>
  </div>
</LiveExample>

For responsive, content-driven spacing between children, prefer the
[`gap` inputs on layout primitives](/layouts/layout/).
