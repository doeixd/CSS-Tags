Effect utilities cover elevation and overlays. Border radius lives with the
[border utilities](/utilities/borders/) because connected-corner composition
depends on logical edges.

## Elevation

Use `.shadow-sm`, `.shadow` / `.shadow-md`, `.shadow-lg`, `.shadow-xl`, or
`.shadow-inner`. Every value comes from the theme shadow scale.

<LiveExample title="Choose elevation by relationship" description="Small shadows separate controls, medium shadows lift cards, and large shadows suit temporary floating surfaces.">

## Scrims

`.scrim` uses the standard dark overlay token; `.scrim-light` uses the light
counterpart. A scrim supplies only color so the owning component remains in
control of positioning and stacking.
