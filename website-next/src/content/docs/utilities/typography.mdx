Typography utilities are for local exceptions such as metadata, labels, or a
display figure. Keep headings semantic—use the appropriate heading element
before reaching for a size class.

## Size scale

The scale runs from `.text-xs`, `.text-sm`, `.text-base`, `.text-lg`, and
`.text-xl` through `.text-2xl`, `.text-3xl`, `.text-4xl`, `.text-5xl`, and
`.text-6xl`.

<LiveExample title="Move through the type scale" description="UI and display steps share the theme's fluid typography tokens.">

## Weight scale

Use `.font-normal`, `.font-medium`, `.font-semibold`, and `.font-bold`.

## Semantic typography first

```html
<h2>Semantic section heading</h2>
<p class="text-sm text-muted">Optional compact metadata</p>
```

For prose rhythm, heading relationships, captions, eyebrows, and CMS content,
use the [typography system](/core/typography/) rather than rebuilding those
relationships with utilities.
