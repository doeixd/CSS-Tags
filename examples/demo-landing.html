    FAQ

    Common questions before you publish.
    Is this page built with the existing library, or custom section CSS?

    It is now entirely library-first. The dedicated demo stylesheet has been removed so the page showcases primitives, tokens, and utilities directly.

    Can I swap the custom tags for classes or `data-*` hosts?

    Yes. The library's selector conventions support component tags, classes, and `data-*` hosts for most primitives.

    Does the FAQ need JavaScript?

    No. It uses native `details` and `summary`, which matches the project's preference for semantic no-JS disclosure patterns.

    Where should I start if I want to adapt this for the docs site?

    Start from this file, keep the layout primitives, and extract repeated content into site components only if you need that extra reuse.
