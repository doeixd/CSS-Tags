Contact Sales ✓ SSO / SAML FAQ Questions teams ask before they switch Everything Beacon needs to be useful on day one, without adding a new deployment platform learning curve.
Does Beacon replace our current CI pipeline? Beacon can run builds, tests, previews, and production deployments out of the box. Teams with existing CI often start by using Beacon for preview environments and production promotion, then consolidate more pipeline steps over time.
How fast can we migrate an existing app? Most teams ship a first preview in under ten minutes. Beacon auto-detects common frameworks, pulls environment variables, and gives you a working build path before you need to tune anything advanced.
Can we control promotion to production? Yes. You can gate production with approvals, test checks, protected branches, or scheduled rollouts. Preview deployments stay automatic, while production can match however strict your release process needs to be.
What happens with environment variables and secrets? Secrets are scoped by environment and project, with audit history and rotation support. Teams can separate preview, staging, and production credentials without duplicating app configuration manually.
Is Beacon only for frontend apps? No. It works well for frontend frameworks, APIs, background services, and multi-service repos. The platform is designed around deployments and observability, not a single framework or runtime.
