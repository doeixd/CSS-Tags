Designing for the space between elements

A good type system is less about isolated sizes and more about the relationships that make a page understandable at a glance.

Typography creates a map before a reader has processed a single sentence. Headings establish territory, body copy provides the route, and captions explain the details that would otherwise interrupt the journey.

Start with semantic structure

Choose elements for the document outline and reading order. Styling can then enhance those relationships without replacing them.

  • Use one page-level heading that clearly names the subject.
  • Keep heading levels sequential where practical.
  • Use lists when items genuinely form a set.
  • Let figures, quotes, and code keep their native meaning.

Consistency is not making every element identical. It is making every relationship predictable.

Rhythm belongs to relationships

A heading should sit closer to the content it introduces than to the section before it. The prose layer expresses those relationships with rhythm tokens rather than unrelated margins.
