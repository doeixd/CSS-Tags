CSS Tags ships as the `css-tags` package. Its root entry is the complete
layered stylesheet and exposes the custom-tag DOM and JSX declarations.

## Install

```bash
npm install css-tags
```

```css
@import "css-tags";
```

```ts
/// <reference types="css-tags" />
```

## Add a generated theme

```css
@import "css-tags";
@import "./my-theme.css";
```

The generated file uses a trailing `css-tags-theme` layer so its token
declarations win without selector escalation.
