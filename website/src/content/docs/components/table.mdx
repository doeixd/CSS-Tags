CSS Tags enhances native tables instead of replacing their accessibility model. Add `data-table` or `.data-table` to a `<table>`. For narrow containers, wrap it in `<data-table>`, `[data-table-scroll]`, or `.table-scroll`.

Tables and their optional scroll wrappers fill the available inline size by
default. The shipped surface, header, stripe, divider, and hover colors are
intentionally quiet; increase them through table tokens only when the dataset
needs stronger separation.

```html
<data-table tabindex="0" aria-label="Scrollable deployment table">
  <table data-table class="table-hover">
    <caption>Recent deployments</caption>
    <thead>
      <tr>
        <th scope="col">Environment</th>
        <th scope="col">Version</th>
        <th scope="col">Status</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th scope="row">Production</th>
        <td>v2.8.0</td>
        <td>Healthy</td>
      </tr>
    </tbody>
  </table>
</data-table>
```

## Why the wrapper matters

Changing every cell to `display: block` can obscure row and column relationships and requires duplicated `data-label` content. CSS Tags keeps the native table intact and makes only its wrapper scroll. `tabindex="0"` lets keyboard users reach the scroll region; use an accessible label when the surrounding heading does not already describe it.

For a table used directly without a wrapper, CSS Tags provides a small-screen overflow fallback:

```html
<table class="data-table table-striped">
  <!-- normal table structure -->
</table>
```

## Variants

- `.table-striped` adds alternating row surfaces.
- `.table-hover` highlights the row under the pointer.
- `.table-bordered` uses the thick border token.
- `.table-borderless` removes the outer border and row dividers.

## Theme tokens

```css
.billing-table {
  --table-min-width: 44rem;
  --table-cell-padding-block: 0.75rem;
  --table-cell-padding-inline: 1rem;
  --table-heading-bg: var(--table-heading-background);
  --table-stripe-bg: var(--table-stripe-background);
  --table-row-hover-bg: var(--table-hover-background);
}
```

The global defaults are `--table-background`, `--table-border-color`,
`--table-divider-color`, `--table-heading-background`,
`--table-stripe-background`, and `--table-hover-background`. The shorter
component aliases shown above are useful for styling one table.

## Accessibility checklist

- Use `<caption>` when a visible name helps identify the dataset.
- Add `scope="col"` to column headers and `scope="row"` to row headers.
- Keep sorting controls as real buttons inside header cells and expose direction with `aria-sort`.
- Do not use a table for visual page layout.
